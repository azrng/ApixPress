对外说明 + 工程概览

ApixPress 整体架构

ApixPress 是一个本地桌面端 API 协作与调试工具，围绕项目工作区、OpenAPI/Swagger 导入、HTTP 请求调试、用例管理、环境变量、请求历史和本地 SQLite 持久化构建。当前代码未接入 AI Agent 或模型 Runtime，本图以真实桌面应用架构和外部集成为主。

.NET 10 / WinExeWindows x64 自包含单文件发布
Avalonia 12桌面 UI、Fluent、Semi.Avalonia、Ursa
CommunityToolkit.MvvmViewModel、RelayCommand、状态通知
Dapper + Microsoft.Data.Sqlite本地数据仓储和迁移初始化

工程事实

主入口Program.Main 启动 Avalonia；更新模式由 AppUpdateRunner 接管。
依赖注入ServiceBootstrapper 加载内嵌与外部 appsettings.json，并注册业务服务。
持久化默认数据库为 data/ApixPress.db，用户设置可指定存储目录。
测试ApixPress.App.Tests 使用 xUnit，覆盖服务、仓储、ViewModel 和布局约束。

用户入口

用户从 MainWindow 进入首页、项目标签、接口工作区、快捷请求、设置中心、环境变量抽屉和用例管理抽屉。

外部渠道入口

支持从本地 JSON 文件或 URL 导入 Swagger/OpenAPI 文档；HTTP 请求通过 RequestExecutionService 访问目标 API 服务。

恢复 / 配置入口

DatabaseInitializer 执行迁移和旧数据归并；AppShellSettingsService 管理超时、SSL、重定向、日志、存储目录和更新提醒配置。

主业务 Pipeline

1

启动与初始化

Program / App / ServiceBootstrapper

加载配置、构建 DI 容器、创建主窗口，启动时先完成数据库初始化和 Shell 状态加载。

2

打开项目工作区

MainWindowViewModel / ProjectTabViewModel

项目列表进入多标签工作区，项目标签常驻实例复用，降低切换和重新挂载成本。

3

导入预检查

ApiWorkspaceService / OpenApiImportPreviewBuilder

读取 URL 或文件，解析 OpenAPI JSON，识别新增、覆盖和冲突接口，触发覆盖确认流程。

4

预处理缓存

OpenApiPreparedImportCache

预览后的解析图短期缓存，导入确认时复用；支持过期淘汰、容量上限和确认后取出。

5

接口与用例编排

ProjectRequestWorkflowViewModel / RequestCaseService

接口树、根目录工作区、快捷请求和保存用例协同，维护标签、脏状态、固定标签和关闭保护。

6

请求构建与发送

RequestExecutionService

替换 {{variables}}、拼接 BaseUrl、处理路径与查询参数、构造 Body 和 Header 后通过 HttpClient 发送。

7

异常与大响应保护

ResultModel / ResponsePreviewByteLimit

区分取消、超时、HTTP 失败和通用异常；响应正文预览限制为 1 MB，并标记截断状态。

8

保存与输出

Repository / ProjectDataExportService

接口、参数、用例、历史、环境与项目认证写入 SQLite；项目数据包可导出为可复用 JSON 文件。

外部依赖与集成

桌面 Runtime

Avalonia Desktop、Fluent、Semi.Avalonia、Ursa 提供窗口、主题、抽屉、弹窗和控件能力。

OpenAPI 来源

本地 JSON 文件与远程 URL 是当前导入入口；远程 URL 失败会返回超时或 HTTP 错误说明。

目标 API 服务

请求调试通过 HttpClient 访问用户配置的 API 服务，支持 SSL 校验、重定向、超时和 no-cache Header 配置。

GitHub Releases

更新检查读取 versions.json 清单；当前为可配置通道，不等同于强制自动更新。

当前不包含

代码中未发现 AI 模型服务、Agent Runtime、消息队列、远程多租户后端、云数据库或用户权限系统。相关能力不在本架构图中虚构展示。

核心模块

View / UI

Avalonia XAML 控件负责桌面交互与工作区布局。

  • MainWindowHomeView、MainWindowTitleBarView
  • ProjectWorkspaceView、ProjectWorkspaceSidebarView
  • HttpInterfaceWorkbenchView、QuickRequestWorkbenchView
  • SettingsDialogView、NotificationCenterOverlayView

ViewModel / Application

承载用户命令、工作区状态、标签生命周期和 UI 数据。

  • MainWindowViewModel 与 Shell 状态同步
  • ProjectTabViewModel 与 ProjectTabComposition
  • ProjectRequestEditorViewModel、RequestWorkspaceTabViewModel
  • ProjectImportViewModel、MainWindowSettingsViewModel

Service

封装导入、请求、用例、环境、设置、更新和系统数据操作。

  • ApiWorkspaceService、RequestExecutionService
  • ProjectWorkspaceService、RequestCaseService
  • EnvironmentVariableService、ProjectHttpSettingsService
  • ApplicationUpdateService、SystemDataService

Tool / Parser

当前没有 AI 工具链；这里展示工程内解析与辅助工具。

  • OpenApiJsonParser 解析 OpenAPI JSON
  • OpenApiImportSourceReader 读取文件或 URL
  • OpenApiPreparedImportCache 缓存预处理结果
  • ProjectHttpDocumentFormatter 生成文档预览

Repository / Storage

Dapper 仓储围绕 SQLite 表结构读写项目、接口和请求数据。

  • ProjectWorkspaceRepository、ApiDocumentRepository
  • RequestCaseRepository、RequestHistoryRepository
  • ProjectEnvironmentRepository、EnvironmentVariableRepository
  • DatabaseInitializer 与 schema_migrations

Channel / Integration

集成点集中在本地文件、远程 URL、目标 API、更新包和系统进程。

  • FilePickerService 选择导入、导出与存储路径
  • RequestExecutionService 连接目标 HTTP API
  • ApplicationUpdateService 读取更新清单并启动隐藏更新模式
  • ApplicationRestartService 支持清空数据后的重启动作

核心数据模型

ProjectWorkspaceDto / Entity项目工作区基础信息，包含名称、描述、默认项目和更新时间。
ProjectEnvironmentDto / Entity项目环境与 BaseUrl，配合激活环境和变量替换使用。
EnvironmentVariableDto / Entity环境变量键值与启用状态，用于 {{key}} 替换。
ApiDocumentDto / Entity导入的 OpenAPI 文档元数据、来源、BaseUrl 和原始 JSON。
ApiEndpointDto / Entity接口分组、方法、路径、描述、Body 模式与请求体模板。
RequestParameterDto / Entity接口参数，覆盖 query、path、header 等参数类型。
RequestSnapshotDto一次请求的完整快照，包括 URL、方法、参数、Header 和 Body。
ResponseSnapshotDto响应状态码、耗时、大小、Header、正文预览与截断标记。
RequestCaseDto / Entity保存用例、分组、目录、标签和请求快照。
RequestHistoryEntity保存请求历史的请求快照和响应快照。
ProjectHttpAuthSettingsDto项目级认证配置，当前支持 none、Bearer Token 和 Basic Auth。
ProjectDataExportPackageDto项目数据导出包，承载可复用的项目、接口和用例数据。

横切能力

配置管理内嵌 appsettings.json 与发布目录外部配置叠加；Shell 设置保存到用户数据目录。
迁移与恢复DatabaseInitializer 维护 schema_migrations，处理旧版单项目数据迁移。
缓存控制导入预览缓存有过期和容量限制；HttpClient 共享缓存限制为 16 个配置组合。
异常处理服务层返回 IResultModel，区分取消、超时、HTTP、解析和通用失败。
性能保护响应正文预览上限 1 MB，部分视图采用懒挂载、常驻实例和批量集合更新。
通知与状态AppNotificationService、通知中心、状态栏和 loading overlay 展示运行反馈。
测试体系xUnit 覆盖数据库初始化、服务、仓储、ViewModel 生命周期和工作台布局。
发布部署Release 配置启用 win-x64、自包含、单文件、ReadyToRun 和单文件压缩。

数据流向

用户输入 / 外部请求

项目创建、OpenAPI URL/文件、接口点击、快捷请求、环境变量和设置项。

应用编排

ViewModel 接收命令，更新工作区标签、状态、抽屉和弹窗。

规则与上下文

导入冲突预览、覆盖确认、环境选择、变量替换、项目级认证注入。

业务服务

Service 层处理导入、请求发送、用例保存、历史记录和数据导出。

工具 / 外部调用

OpenAPI 读取与解析、HttpClient 访问目标 API、更新清单读取。

持久化

Dapper Repository 写入 SQLite 表：projects、api_documents、request_cases、request_history 等。

结果输出

回填 UI 响应区、接口树、用例列表、通知中心、导出文件或更新流程。

输出与应用

接口工作区

导入后的接口树、根目录工作区、Auth 配置和接口详情编辑。

请求调试结果

状态码、耗时、大小、Header、响应正文预览、格式化和搜索提示。

本地数据资产

SQLite 中的项目、环境、接口、参数、用例、历史和认证配置。

文件与更新

项目数据包导出、外部配置覆盖、发布包更新检查和隐藏更新启动请求。

图例

用户操作或业务数据从入口进入应用编排、服务、外部调用和输出。

重试 / 恢复

导入预览缓存、旧数据迁移、更新启动和错误恢复等非主干控制流。

读写交互

Repository、SQLite、文件系统、配置和导出包之间的读写关系。
