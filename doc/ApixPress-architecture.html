5. 核心数据模型

ProjectWorkspaceDto项目空间、默认项目和更新时间。
ApiDocumentDto / ApiEndpointDtoOpenAPI 文档、接口分组、方法、路径和请求模板。
RequestSnapshotDto一次 HTTP 请求的 URL、参数、Header 和 Body 快照。
ResponseSnapshotDto状态码、耗时、大小、Header、正文预览和截断标记。
RequestCaseDto / RequestHistoryEntity保存用例和请求历史。
ProjectHttpAuthSettingsDto项目级 none、Bearer Token、Basic Auth 配置。
