# 新版工作台改造（首页主窗口与项目 Tab 化，已实施）

> 原文标注「需求草案」；Tab 化视图均已落地（对应 DES-006），待确认项已按实现拍板收敛。

## 12.1 目标

首页直接作为主窗口工作台；项目打开新开 Tab 并行使用。

## 12.2 页面与模块调整

| 模块/页面 | 调整内容 | 目标 |
| --- | --- | --- |
| 主窗口顶部 | 首页 Tab、项目 Tab、顶部操作区 | 统一承载首页和多个项目工作区 |
| 首页内容区 | 默认展示项目列表 | 保留项目入口 |
| 项目工作区 | 新开 Tab 而非整页替换 | 并行查看多个项目 |
| 左侧 | 轻量导航，突出接口管理 | 减少概览卡片堆叠 |
| 中间 | 直接展示快捷请求编辑器 | 进入即发请求 |
| 右上 | 窄环境选择入口 | 强化切换即时性 |
| 环境管理 | 双栏管理界面 | 环境名/前置 URL/变量集中维护 |

## 12.3 核心业务流程调整

启动默认进首页 → 点项目卡片新开 Tab 并切换 → 每 Tab 独立环境/接口入口/编辑状态 → 右上下拉只切当前 Tab 环境 → 环境设置打开独立管理界面真实编辑保存。

## 12.4 关键约束

首页支持新建项目弹框（名称+备注）；项目 Tab 可关闭且不影响数据；Tab 切换恢复对应环境/历史/工作区状态；环境修改真实落库；快捷请求支持环境变量解析。

## 12.5 待确认项（已按实现拍板）

- 顶部仅「首页 + 项目 Tab」，无返回按钮 — **已实施**
- 同项目不重复开 Tab，已开则激活已有 — **已实施**
- 项目中间区域仅快捷请求一个主工作区 — **已实施**
- 环境管理仅项目级，不做全局变量/Vault — **已实施**
