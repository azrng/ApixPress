# 请求用例交付需求

## 需求追溯

本需求对应 `TASK.md` 的 T077，覆盖请求用例交付清单中的 UC-07、UC-08、UC-09。项目完整备份、HTML/Markdown 文档导出和请求用例基础链路继续由 [项目数据导出需求](../project-data-export.md) 与请求用例交付优化清单维护，本文件只定义可选择、可恢复导入的请求用例交付包。

## 业务目标与范围

项目用户可以把当前项目中选定的接口和请求用例交付给另一个项目。导入后，接收项目可以直接加载和发送请求用例，不需要手工补父接口或重新绑定环境。

交付包包含：

- 用户选择的接口定义；选择请求用例时自动包含其父接口。
- 用户选择的请求用例及其完整请求配置：方法、URL、Params、Path 参数、Headers、Body 和其他已保存请求配置。
- 项目级环境配置：前置 URL、环境名称、变量名、变量值、启用状态和当前环境标记。
- 格式版本、导出时间和来源项目标识、名称等来源信息。

交付包不包含响应历史、断言、预期响应、测试结果、测试报告或其他项目完整恢复数据。API Key 的显示和脱敏策略沿用当前产品策略，本需求不新增策略。

## 用户与入口

单机项目用户从项目设置的“请求用例交付”入口进入。项目完整备份继续从独立的“项目备份”入口进入，两者不能共用范围选择状态，也不能把交付包当作项目完整恢复包。

## 核心流程

1. 用户打开请求用例交付入口，看到接口树及其下级请求用例，并选择一个或多个接口、请求用例。
2. 系统自动补齐所选请求用例的父接口，并读取项目级环境配置。
3. 导出前显示将交付的接口数、请求用例数、环境数和变量数；用户确认后生成交付包。
4. 接收项目选择交付包后先解析并预览接口、请求用例、环境及冲突，不写入项目。
5. 用户按接口、请求用例和环境选择覆盖、跳过或另存；孤儿项必须显示并默认阻止导入。
6. 用户确认后一次性写入接口、请求用例和环境。全部成功才提交；取消、取消令牌或任一写入失败时回滚本次导入。

## 业务对象与字段含义

字段结构以 `CON-T077` 契约草案为准。这里仅规定业务含义：

- **来源项目**：产生交付包的项目命名空间；与实体来源 ID 一起构成稳定来源标识。
- **接口来源 ID**：导出项目中接口的稳定来源 ID，只用于交付包内部关联和重复导入识别，不直接作为目标数据库 ID。
- **请求用例来源 ID**：导出项目中请求用例的稳定来源 ID；必须引用同包接口来源 ID。
- **环境来源 ID**：导出项目中环境的稳定来源 ID；变量通过环境来源 ID 和变量名关联。
- **父子引用**：请求用例必须通过包内父接口来源 ID 关联接口，不依赖导入后的数据库 ID、方法路径键或接口名称。

## 权限与可见范围

本地项目用户只能导出当前项目可见数据；导出和导入均以当前 `ProjectId` 为边界，不读取或写入其他项目数据。交付包中的环境变量值按用户明确选择的范围随包保存，文件访问安全由操作系统和当前应用策略负责。

## 边界与异常

- 未选择任何接口和请求用例时禁止生成空交付包，并提示用户至少选择一项。
- 选择的请求用例缺少父接口时，导出前报告孤儿项并阻止生成。
- 交付包格式版本不支持、内容损坏或超过文件大小限制时，预览失败且不写入目标项目。
- 接口、请求用例或环境冲突必须逐项显示；未决冲突不能进入提交阶段。
- “另存”生成新的目标实体标识；若名称冲突，按现有命名规则生成不冲突名称并在预览中展示。
- 导入过程中取消、校验失败或任一持久化失败时，目标项目不保留本次导入的接口、请求用例或环境。
- 当前项目已有活动环境时，默认不被交付包中的活动标记替换；目标项目没有活动环境时，才采用交付包的活动环境标记。

## 非功能要求

- 预览不产生写入副作用；导入提交具备事务性。
- 同一交付包多次预览和导入使用稳定排序和稳定来源标识，结果可解释。
- 导出、预览、导入均支持取消，不阻塞界面。
- 导入后的请求用例可以直接加载和发送，父接口和环境引用完整。

## 验收标准

- 项目备份与请求用例交付有独立入口和独立范围；备份仍可用于完整恢复。
- 只选择请求用例时，交付包自动带上父接口；不产生孤儿请求用例。
- 接口改名、跨项目导入、多个来源存在相同方法和路径时，仍按包内父子关系恢复。
- 预览显示接口、请求用例、环境、变量及各类冲突数量，并区分新增、更新、跳过、另存和孤儿项。
- 用户可逐项选择覆盖、跳过或另存；默认策略在文档定稿后固定。
- 导入成功后一次提交；失败或取消后目标项目没有半成品数据。
- 交付包不包含响应历史、测试结果和报告。

## 已确认规则

1. 同一来源项目和来源 ID 默认更新；不同来源但业务键冲突默认跳过；用户可逐项改为覆盖、跳过或另存。
2. “另存”使用 `_copy` 命名规则，并在仍冲突时追加数字后缀。
3. 默认导出当前项目全部环境；导入时已有活动环境不被替换，目标无活动环境时采用包内活动标记。
