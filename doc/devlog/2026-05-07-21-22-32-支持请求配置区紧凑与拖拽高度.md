# 支持请求配置区紧凑与拖拽高度

## 本次目标
- 当前请求配置页没有参数或内容时，自动缩短请求配置区高度。
- 在请求配置区和返回响应区之间增加可拖拽分隔条。

## 核心改动
- HTTP 接口工作台和快捷请求工作台改为配置区按内容自适应高度、响应区占剩余空间。
- 为请求配置区设置最小高度和最大高度，空参数时自然收缩，有内容时可向下扩展。
- 在请求配置区与响应区之间增加 `GridSplitter`。
