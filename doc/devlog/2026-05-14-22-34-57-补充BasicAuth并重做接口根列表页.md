# 补充 Basic Auth 并重做接口根列表页

## 本次目标
- 为接口根 Auth 补充 Basic Auth。
- 将「全部接口」页改成全宽紧凑工作台布局，修复表格漂浮、内容松散的问题。

## 核心改动
- 扩展项目级 HTTP Auth DTO、实体、Repository 与 Service，支持 `basic` 模式、用户名和密码。
- 数据库 schema 版本提升到 `3`，初始化与迁移逻辑补齐 `basic_username`、`basic_password` 字段。
- HTTP 接口发送时支持应用项目级 Basic Auth，并继续保持接口自身 `Authorization` Header 优先。
- Auth 表单新增 Basic Auth 用户名与密码输入。
- 「全部接口」页改为全宽工作台容器：标题、筛选条、表头和列表共用稳定列宽，避免内容漂在中间。
- 增加服务、发送链路和界面结构回归测试。
