# 优化响应区大内容处理性能

## 本次目标
- 降低响应区展示大 JSON/XML 正文和搜索大正文时的 UI 卡顿风险。

## 核心改动
- 响应正文超过 256KB 时跳过同步 JSON/XML 格式化，直接展示原始正文。
- 响应正文超过 1MB 时跳过全文搜索计数，并展示明确提示。
- 补充大正文搜索和大 JSON 展示的回归测试。

## 修改文件
- `src/ApixPress.App/ViewModels/ResponseSectionViewModel.cs`
- `tests/ApixPress.App.Tests/ViewModels/ResponseSectionViewModelTests.cs`
- `TASK.md`

- 已执行：`dotnet test tests\ApixPress.App.Tests\ApixPress.App.Tests.csproj`

## 风险或遗留项
- 大响应体不再自动格式化，优先保证界面响应速度；后续可考虑增加手动格式化入口或后台格式化。
- 本轮未调整接口目录搜索防抖，避免改变现有输入后立即过滤的交互语义。
