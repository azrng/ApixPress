# 限制空配置页拖拽高度

## 本次目标

- 修复 Params、Headers、空 Body 等无配置内容场景下，拖拽请求配置区后仍出现大面积空白的问题。

## 核心改动

- 在 `RequestConfigTabViewModel` 增加 `ConfigPanelMaxHeight`，根据当前配置页和内容状态动态返回紧凑或展开高度。
- 将 HTTP 接口与快捷请求工作台的配置区最大高度绑定到 `RowDefinition.MaxHeight`，让拖拽边界约束作用到实际被 `GridSplitter` 修改的行。
- 补充空配置页、Body raw、空 form-data、有参数配置页的高度回归测试。
- 补充 UI 子规则：可拖拽布局必须约束父级行列定义，不能只约束子控件。
