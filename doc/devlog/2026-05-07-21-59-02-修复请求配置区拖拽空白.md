# 修复请求配置区拖拽空白

## 本次目标

- 修复请求配置区与响应区拖拽调整高度后，请求地址栏下方出现大面积空白的问题。

## 核心改动

- 将 HTTP 接口工作台的可拖拽区域收进内层三行 Grid，分隔条只调整请求配置区与响应区，不再和上方接口设计说明行共享父级行高。
- 增加工作台分隔条布局结构测试，防止后续再次把分隔条放回包含额外顶部行的父级 Grid。
- 为视图实例化测试补充 Avalonia 平台初始化，避免 `GridSplitter` 光标服务缺失导致单元测试环境抛异常。
