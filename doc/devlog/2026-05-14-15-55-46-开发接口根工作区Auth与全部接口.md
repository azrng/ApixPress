# 开发接口根工作区 Auth 与全部接口

## 本次目标

- 点击项目左侧接口根节点后，右侧显示接口根工作区，并默认选中 Auth。
- 先实现 HTTP 接口全局 Auth 的 Bearer Token 能力，只影响 HTTP 接口发送。
- 补充全部接口总览，支持查看和打开当前项目所有 HTTP 接口。

## 核心改动

- 新增项目级 HTTP Auth 设置 DTO、实体、Repository 与 Service，并补齐 SQLite 初始化表。
- 新增接口根工作区 ViewModel 与 Avalonia 视图，包含 Auth 与全部接口两个页签。
- 打通左侧接口根节点点击到右侧工作区展示的导航链路。
- 发送 HTTP 接口时应用项目级 Bearer Token；接口自身启用的 Authorization Header 优先。
- 项目初始化时加载已保存 Auth，确保不打开根配置页也能在发送 HTTP 接口时生效。
