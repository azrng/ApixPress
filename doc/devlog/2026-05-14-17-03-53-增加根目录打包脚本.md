# 增加根目录打包脚本

## 本次目标

- 在项目根目录提供一个可直接运行的打包脚本。
- 脚本运行后自动发布 Windows x64 单文件 exe 到固定输出目录。

## 核心改动

- 新增 `package.ps1`，默认发布 `src/ApixPress.App/Apifox.App.csproj`。
- 默认使用 `Release`、`win-x64`、自包含、单文件发布配置。
- 默认输出到 `artifacts/package/win-x64/ApixPress.exe`，并在脚本末尾校验 exe 是否生成。
- README 补充本地打包命令、默认输出目录和可覆盖参数说明。

## 修改文件

- `package.ps1`
- `README.md`
- `TASK.md`

## 校验情况

- 已执行：`.\package.ps1`，通过，生成 `artifacts/package/win-x64/ApixPress.exe`。
- 已执行：`dotnet build ApixPress.slnx`，通过。

## 风险或遗留项

- 脚本当前默认面向 Windows x64 桌面发布；如需 macOS、Linux 或安装包格式，需要追加运行时和打包策略。
