AApixPress 界面高保真原型
对标 Apifox 深色风格的本地 API 工作区。各页面为真实界面沉浸式展示（无原型辅助栏）， 请直接使用应用自身的导航：顶部目录标签页（首页 / 项目）、 项目内请求标签页与 左侧功能栏（接口管理 / 请求历史 / 项目设置）均可点击跳转； 环境芯片下拉、抽屉与弹窗等交互均可操作。所有页面共享 shared.css 中的设计 token， 本轮为青灰层次与交互反馈的视觉提案，确认后同步到 Avalonia 资源；首页空状态已按反馈改为靠上左对齐。
