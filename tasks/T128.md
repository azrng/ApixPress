# T128 请求头下拉精简与美化

## 结论

- 内置 Header 候选 31 → 13 常用项（`CommonRequestHeaders.Names`），交互口径不变（空输入点击/↓ 展开全部、包含匹配过滤、自由输入）。
- 弹层观感经**应用级资源桥接**落地：`Shadows.axaml` 尾部新增 `AutoCompleteBoxPopup*` 7 个键的覆盖（8px 圆角、1px 描边 #394754、Shadow.Lg、背景 #2B3642、内衬 4、顶距 4），与既有 `SemiColor*` 桥接同一模式。
- 顺带升级 Microsoft.Data.Sqlite / Extensions.Configuration(.Json) / DependencyInjection 10.0.14 → 11.0.0（UI 栈 Avalonia 12.1.6 / Semi 12.1.0.1 / Ursa 2.3.1 已是最新）。
- 验证：构建 0 错；508 测试全绿；图片子代理像素级核对确认背景/描边/圆角/内衬精确生效（弹层 576px → 248px）。

## 关键坑位（Popup 资源链）

- **Popup 内容不走视图资源链**：`UserControl.Resources` 与派生 `ControlTheme.Resources`（BasedOn Semi 主题）对 Semi 弹层模板内的 Border/ListBox 均不生效，实测两条路都失败。
- **应用级资源能命中**：把 Semi 的 `AutoCompleteBoxPopup*` 键直接覆盖在 `Shadows.axaml`（App 合并字典）即生效；此法作用域=全应用所有 ACB 弹层（现仅 Headers 页签 + 导入对话框两处，统一观感可接受）。
- `ListBoxItem*` 键（条目内衬/行高/hover 色）是全局的，动它波及所有列表，本次未动；Semi 的 ACB 模板只转发 `ItemTemplate` 不转发 `ItemContainerTheme`，无干净的局部作用域手段。选中色已由既有 `SemiColorPrimaryLight` 桥接成品牌 #2A2748。
- Semi 主题源码获取路径（GitHub 不通时）：ilspycmd 反编译 DLL → 模板结构在 `!AvaloniaResources.Build:/Controls/AutoCompleteBox.axaml` 一带；资源键默认值在 Themes/Light|Dark 段（如 `AutoCompleteBoxPopupPadding=0,4,0,4`）。
- 待用户裁决项：条目行高保持 Semi 默认 18px 紧凑行（原型为 ~26px 疏松行）；阴影用锁定 token `Shadow.Lg`（较原型 0.45 黑更淡，token 体系内最重档）。
